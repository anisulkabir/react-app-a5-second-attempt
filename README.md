# react-app-a5-second-attempt

This is a responsive React app for exploring React application development techniques.

## a few noteworthy featues of this implemention includes:

- Dynamic card components are utilized to display different information.
- Duplicate prevention is consoderd while implementing selections for stack.
- Some event feedback is displayd using toast notification.
